🌍 TravelMate

TravelMate is a smart travel companion app designed to simplify trip planning and enhance travel experiences. It allows users to discover destinations, create itineraries, and get real-time updates — all in one place.

🚀 Features

🧭 Destination search with filters (location, budget, interests)

🗓️ Itinerary planner with calendar integration

🔔 Real-time travel alerts (weather, flight, etc.)

📍 Nearby places and recommendations

💾 Offline mode for saved plans

🛠️ Tech Stack

Frontend: Blazor, ASP.NET MVC

Backend: C#

Database: MySQL 

APIs: Google Maps API, Weather API 

📌 Why I Built This

While planning trips with my family and friends, I noticed how time-consuming it was to manage multiple apps for different purposes. TravelMate brings everything together in one intuitive platform, helping users save time and travel smarter.
